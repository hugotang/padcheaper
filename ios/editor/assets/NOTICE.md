# PADDashFormation icon assets

`awoken.png` and `latent.png` are unchanged copies of `images/awoken.png` and
`images/icon-latent.png` from [Mapaler/PADDashFormation](https://github.com/Mapaler/PADDashFormation)
at revision `b6c56dc1a67c3d72767e3d6a1ba3ffa373d2895f`. Its GPL-3.0 license is
included as `PADDashFormation-LICENSE`; retain this notice and license when
distributing the embedded editor. Game artwork remains attributed to GungHo
Online Entertainment. These asset files are not relicensed under this
repository's MIT license.

`badge.png` is an unchanged copy of `images/badge.png` from the same project
at revision `fbbafa14ed1364842e783ba4db4680d1b3a8d525` (retrieved 2026-11-07).
It uses the same separately retained GPL-3.0 license and game-art attribution.
Its SHA-256 is `4860df05ffd2f5bd0cb782001f56e12eb7eef431019a45c765dc1b6d9f92a076`.
The editor's `badge-catalog.json` records public identifier/order facts and
independently written category labels; it does not copy upstream code or
claim native badge eligibility or exact gameplay effects. Its source revision
and the share-format differences are recorded in
[`badge-catalog-20261107.json`](../../research/badge-catalog-20261107.json).

The application code, layout and team model are independently implemented.
Only public facts and these separately attributed image files are bundled;
no upstream JavaScript or stylesheet is executed or incorporated.
