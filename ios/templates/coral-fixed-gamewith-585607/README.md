## 逐層流程

「攻擊」＝首消六色＋心四連，優先增加實際四顆消除組數。「存技」＝首消六色、既有盤面所有確定消除皆無四顆組。「L」＝火／木／光其中一色。未來天降不在求路器可保證的範圍。

兩份攻略沒有明訂首消六色，也未區分既有珠落下的連鎖與隨機天降；首消限制是本工具的保守政策。r5 唯一例外為已核對原生時序的 B2 一色不可消分支：受阻色可在回復後的既有珠連鎖消除；若受阻的是心，仍須四顆。這不把後續心四計入首消回復或荊棘／毒珠條件，也不估計天降、傷害或減傷。

本固定 plan 允許單人轉轉取色（fishing）：0.5.50 在普通路徑未達標時，依既有單次／連續取色條件規劃。待建置的新版也讓成功的普通攻擊路徑嘗試增加四消；單次／連續取色共用額外搜尋截止時間，失敗保留原路線，取色後仍須通過目前步驟的全部要求。B2 日誌未進入取色，原因是原生操作時間約 4.27 秒，短於保守預留的六色色循環約 6 秒加交換／放手時間；B5 則是普通路徑達標導致略過，兩者原因不同。B3 的整段操作上限也仍適用，不能因取色延長。
