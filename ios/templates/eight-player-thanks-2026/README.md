此版 JSON 需要 0.5.22-orbs 或之後版本。在轉珠面板開啟「隊伍／關卡策略」，從檔案匯入 `activity-profile.json`，儲存並選用。若已匯入同名策略，先在草稿刪除舊份再匯入新版；相同 ID 不會直接覆蓋。新版增加攻略開關及 B5 救盤備案，更新 dylib 不會改寫已保存的 JSON。進入本杯後，待開始倒數完成、自己的盤面可操作，按一次 Auto，至結算停止。

活動資料可單獨更新並重新匯入。現版不會只憑角色名稱辨認活動，會核對六格固定版本、原生技能效果、CD、雙隊長、盤面尺寸及樓層範圍。不符合時停止並保留診斷。普通單人隊伍策略不適用；選「通用設定」則只自動轉珠，不替你決定技能。

「按 GameWith 樓層攻略開技」預設關閉，維持先試現盤、缺珠才救盤。開啟並儲存後：B2 位置 2、B3 位置 3、B4 位置 1 赤龍女（備案位置 6）、B5 位置 6 赤龍女（不夠 12 時先位置 4 火奈）、B6 火奈可用時 4→2，已用時試位置 2，必要時補位置 3。即使現盤能轉也先開本層技能，每次生效後重讀；兩格赤龍女分開追蹤充能。指定技能不就緒且無備案就停止，不偷偷略過。B5 現盤救援也包含位置 1／2。Stop→Auto 保留本層已確認的技能，不重放開場；同層第二盤按現盤救援。

分數權重只是選路偏好，不是遊戲精確總分或擊倒保證。伊弗利特的對手暗闇技能不自動使用；缺少生存依據時也不刻意消一回合等 CD。若本層沒有可用替代技能或未找到達標路徑，Auto 停止，可手動接手。此版不重新配對。

實機固定技能相容性、服務端同步、無天降時序、消法與最終計分尚待裝置驗收。模擬資料通過不等同真機通關。
