此版 JSON 需要 0.5.24-orbs 或之後版本。在轉珠面板開啟「隊伍／關卡策略」，從檔案匯入 `activity-profile.json`，儲存並選用。若已匯入同名策略，先在草稿刪除舊份再匯入新版；相同 ID 不會直接覆蓋。新版優先 B5 火奈→赤龍女，並保留 B6 留珠準備及火珠輸出排序；更新 dylib 不會改寫已保存的 JSON。進入本杯後，待開始倒數完成、自己的盤面可操作，按一次 Auto，至結算停止。

活動資料可單獨更新並重新匯入。現版不會只憑角色名稱辨認活動，會核對六格固定版本、原生技能效果、CD、雙隊長、盤面尺寸及樓層範圍。不符合時停止並保留診斷。普通單人隊伍策略不適用；選「通用設定」則只自動轉珠，不替你決定技能。

來源：[GameWith 攻略](https://xn--0ck4aw2h.gamewith.jp/article/show/586197)，2026-11-02 核對。B1 優先較高首消 Combo，再比消珠數，最後比步數；B2–B4 火／闇橫排；B5–B6 火／闇一組 ≥12，形狀不限兩排。B6 當前吸收與雙隊長都確認時，至少首消 4 Combo＋加算 2。

「按 GameWith 樓層攻略開技」預設關閉，維持先試現盤、缺珠才救盤。開啟並儲存後：B2 位置 2、B3 位置 3、B4 位置 1 赤龍女（備案位置 6）、B5 優先火奈 4→赤龍女 6（備案 4→1），火奈不可用時才考慮珠數可行的單赤龍女；B6 火奈可用時 4→2，已用時優先同回合位置 2→3，條件不符才考慮單位置 2。B5兩技優先是依裝置紀錄所作的穩定取向調整，GameWith原文允許單技足12時保留火奈。每次生效後重讀；兩格赤龍女分開追蹤充能。指定技能不就緒且無備案就停止。B5 現盤救援也包含位置 1／2。Stop→Auto 保留本層已確認的技能，不重放開場；同層第二盤按現盤救援。

B6 火奈已用時，若 #2／#3 最多差一回合、普通盤面能保留足夠轉色珠，且扣除三珠後的攻擊色仍多於現盤／當前可用轉色，攻略優先消一組三珠等雙技；雙技已就緒就直接開。保留量需足夠一色 12、火至少 6，禁止現有珠連鎖，剩餘至少 15 秒。只限本杯 6535／1／B6 的一回合 5 Combo 吸收；最多一次，下一盤重新確認吸收消失及 CD 後才 #2→#3。沒有可驗證準備路徑則停止。停止接續不增加準備額度；舊 JSON 沒有 `preferBeforeOutput` 時保留原本先輸出／救盤的選擇。

火／闇相對權重 3:1，列強、超連消及 Combo 一併比較；闇 12 也可提高火力，不強迫火 12。分數與攻擊權重只是選路偏好，不是遊戲精確總分、傷害或擊倒保證。上述是本杯攻略流程，不包含一般敵人存活預測。若準備條件不符或未找到路徑，Auto 停止，可手動接手。

實機固定技能相容性、服務端同步、無天降時序、消法與最終計分尚待裝置驗收。模擬資料通過不等同真機通關。
