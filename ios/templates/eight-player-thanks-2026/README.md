# 8 人大感謝祭 2026 杯

需要 0.5.19-orbs 或之後版本。在轉珠面板開啟「隊伍／關卡策略」，從檔案匯入 `activity-profile.json`，儲存並選用。進入本杯後，待開始倒數完成、自己的盤面可操作，按一次 Auto。每盤會按當前盤面選路，必要時原生開技，確認效果後繼續下一回合／樓層；到結算停止。

活動資料可單獨更新並重新匯入。現版不會只憑角色名稱辨認活動，會核對六格固定版本、原生技能效果、CD、雙隊長、盤面尺寸及樓層範圍。不符合時停止並保留診斷。普通單人隊伍策略不適用；選「通用設定」則只自動轉珠，不替你決定技能。

來源：[GameWith 攻略](https://xn--0ck4aw2h.gamewith.jp/article/show/586197)，2026-11-02 核對。B1 分割 Combo；B2–B4 火／闇橫排；B5–B6 火／闇 ≥12。先試現盤，再按本層替代序列；兩格赤龍女分開追蹤充能。火奈等隨機技能必須生效後重讀。B6 當前吸收與雙隊長都確認時，至少首消 4 Combo＋加算 2。

分數權重只是選路偏好，不是遊戲精確總分或擊倒保證。伊弗利特的對手暗闇技能不自動使用；缺少生存依據時也不刻意消一回合等 CD。若本層沒有可用替代技能或未找到達標路徑，Auto 停止，可手動接手。此版不重新配對。

實機固定技能相容性、服務端同步、無天降時序、消法與最終計分尚待裝置驗收。模擬資料通過不等同真機通關。
