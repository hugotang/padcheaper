# 0.5.34-orbs：UI 整理、角色圖示與單人 Auto 修正

- 技能規則改為摘要列表，點入展開；角色／技能限制與輪替設定置於進階區。策略分區、說明收合、主要儲存按鈕固定在底部。
- 編隊分為編隊、隊伍試算、關卡對比；編輯角色顯示頭像，潛覺選擇顯示圖示、名稱與格數。潛覺可離線使用，角色頭像沿用網路圖集／WebKit 快取。
- 8 人倒數自動開始移至轉珠頁的全域設定，單獨儲存開關。仍每場一次，手動停止後本場不重啟，不入場、配對或再戰。
- 可選缺珠規則跨轉轉色序時略過技能，Auto 可接續求路與既有撈珠；必要規則仍需確認。
- 單人 Combo 吸收對策計入已確認的隊長／助人／徽章／技能加算；只扣減敵人門檻，保留自訂目標與首消觸發證明。未確認條件不提供加算，仍不支援上限 Combo 吸收。詳見 [Combo 加算](combo-bonus.md)。
- 已核對 mode、獨立 HP 及所屬敵人的部位不再一律阻止單人技能；未知狀態仍停止。每次施放與轉珠前重新核對，8 人原政策不變。詳見 [敵人對策](enemy-countermeasures.md)。
