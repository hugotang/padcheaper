# 0.5.31-orbs：停用轉轉鎖定顏色、全盤鎖定時可穿過轉轉格

## 停用 0.5.30 的轉轉鎖定顏色

0.5.30 假設轉轉自抓珠起停止換色，這個前提錯誤：實機紀錄顯示拖曳中仍會換色，`0x1005AFA74` 清 `impl+600477` 的路徑是點隊員放技能。鎖定路線可能在放手檢查失敗，已移動的路線放開後浪費一回合。此版回到舊行為：所有色序都找不到路線時不移動、直接停止。

## 保留單人求路失敗延長重試

第一次搜尋未達標且不是珠數不足時，以 2000 ms 再搜一次。8 人 Auto、多人與武裝回復多候選不套用。

## 全盤鎖定時可穿過轉轉格

遊戲換色時跳過鎖定珠（`sub_1005ABF34` 檢查 `0x800`）。全盤每顆珠都鎖定時，轉轉格不再封鎖；只要有一顆未鎖定就維持封鎖。封條不變。
