# 0.5.18-orbs：離線隊伍試算與完整覺醒圖示

編隊頁新增單人離線隊伍模型，在地下城外即可比較編隊／最終型態的總 HP、回復力、條件減傷及消心回復估值。切換光三＋心三、光 L＋心四、光 T＋心四或逐組自訂，不會套用隊員或花 stamina。隨機變身需要指定型態，未支援的隊長條件會標示未完整。

全隊覺醒合計、常用異常耐性及每名隊員的本體／超同步／武裝／潛覺圖示都可查看，點圖示顯示名稱與來源。手機個別隊員採三欄，寬螢幕六欄；普通覺醒未開啟、單人無效的協力強化顯示灰色。圖示已內嵌，可離線使用；角色頭像仍需連線。

雨龍基本範本在無額外加成時，變身前 HP 397,834 與既有 dump 一致，變身後為 409,219。光三＋心三與光 L＋心四的雙隊長減傷同為 96.76%；光 T 額外提高回復與 Combo。完整條件及資料來源見 [隊伍試算](team-model.md)。

心珠回復仍是公式估值，不是已驗證的承傷保證；此版沒有接通 Auto 的省 T／光心耐久放行。徽章、關卡專屬倍率及實戰異常不會自動納入。原有全層關卡 dump、敵人 Combo 對策、策略與隊伍庫保留。

本版已通過 Windows 的 25 項隊伍模型及 Edge 編隊瀏覽器檢查。iPhoneOS 編譯、完整原生回歸及四份模擬器 GUI 尚待本版手動 CI；0.5.17 的結果不代替本版驗證。結果更新於 [開發紀錄](development.md)。

更新時完全關閉遊戲，再替換新版 dylib；LiveContainer 需重新簽署。保留原有設定及隊伍庫，開啟「編輯六人隊伍」即可使用試算，不需重進已過關的 dungeon。覺醒圖示原始檔與 GPL-3.0 授權附於 `third_party/PADDashFormation/`。
