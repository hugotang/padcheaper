# 0.5.18-orbs：隊伍模型、主動技能與關卡對比

編隊頁新增單人離線隊伍模型，不需進 dungeon 或消耗 stamina，即可比較編隊／最終型態的總 HP、回復力、雙隊長／覺醒減傷及消心回復估值。全隊與各隊員的本體／超同步／武裝／潛覺都有完整圖示和來源，圖示內嵌離線使用；角色頭像仍需連線。

主動技能列出名稱、CD、持續回合並可切換試算：#3 卯之花 HP／回復 ×3 及 7×6 為 1 回合，#4 哈斯沃德 35% 盾為 5 回合，#5／#6 白哉 HP ×1.5 為 1 回合。同類效果按施放順序逐項覆蓋；提高 HP 上限不補滿新增血量。雨龍基本範本最終 HP 409,219，白哉情境 613,829，卯之花情境 1,227,657；光心隊長盾加 #4 技能盾為 97.894%。

「匯出關卡 JSON…」旁新增「隊伍對比」，直接帶入本次擷取資料，免去匯出再匯入。也可開啟其他全層 JSON。每層顯示觀察／推算 ATK、已讀傷害、日常與救援容量，以及未知分支／狀態。攻略庫可匯入、更新並獨立儲存，換關卡不需重新編譯；隨版附 2026-11-01 GameWith Lv5 留技提示，包括 B9／B13 共用 CD 的衝突。

HP 與回血試算仍有明確界線：未計徽章、完整遊戲狀態或所有隊長／敵人機制，部分數值是估值。此版沒有接通 Auto 的省 T／光心耐久存活放行。詳細用法見 [隊伍模型](team-model.md) 及 [關卡對比與攻略庫](team-dungeon.md)。

本機模型及瀏覽器檢查已通過；本批最終 iPhoneOS arm64 編譯、完整原生回歸與 Scene／舊式視窗首次／重啟共四份 GUI 仍待手動 CI。結果更新於 [開發紀錄](development.md)，先前版本不代替本版驗證。

更新時完全關閉遊戲，再替換新版 dylib；LiveContainer 需重新簽署。原有設定及隊伍庫保留；開啟「編輯六人隊伍」即可試算，已有關卡紀錄則可按「隊伍對比」。圖示原始檔與 GPL-3.0 授權附於 `third_party/PADDashFormation/`。
