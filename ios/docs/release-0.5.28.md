# 0.5.28-orbs：精確形狀依實際消除群組、開場手動變身後接續

## 形狀判定

PAD 23.6.0 `0x1005F7954` 對 T／L／十字只在該組實際消除數 = 5、3×3 在 = 9 時比對模板內的同色已標記珠，不檢查未消除的同色鄰珠。求路器原本對這四種形狀額外禁止任何同色鄰珠，會把遊戲認可的路線判為失敗。現在四種形狀與心四連一樣只看實際消除群組；被標記併入（變成 6 顆以上）仍失敗。引導評分、轉轉穩定模板同步調整，並移除以形狀外框為分隔的預先拒絕（`IncompatibleGoals` 不再產生）。整行／整列不變。

## 開場手動變身後接續

開場的變身步驟（例：雨龍隊位置 1 本體 14037→14038）被敵人延遲 CD 而停止時，手動變身後再按 Auto，會把開場游標推進到該變身步驟之後繼續。只採用有形態證據（`afterMonster`）且技能總計數已增加的步驟；無形態變化的步驟仍由 Auto 施放，CD 未就緒時照常停止，不會跳過。
