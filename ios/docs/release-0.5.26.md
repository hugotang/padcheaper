# 0.5.26-orbs：浮動轉珠列、PC 面板卡片與結構整理

## 浮動控制

原本的「PC」圓鈕依狀態兼任展開、開設定與停止，且狀態只看邊框顏色。改為 48 pt「轉珠」按鈕加一條膠囊列：轉一次、自動（執行中為停止）、⚙ 設定、⌄ 收合。

- 轉珠按鈕只負責展開／收合；執行中顯示「停止」，點一下即停。
- 膠囊列順序固定，「停止」永遠在「自動」那一格。
- 設定只從 ⚙ 進入；執行中 ⚙ 停用，不會誤停工作。
- 膠囊背景不接收觸控，按鈕之間的空隙仍交給遊戲。

## PC 設定面板

原本 25 項排成一長列，改為「常用／隊伍與入場（單人）／外觀與音樂／計時／診斷與 API」五張卡片；功能總開關、編隊與轉珠入口在最上方。按鈕改為與轉珠頁一致的樣式，配色改用系統色。
