# 關卡對比與攻略庫

0.5.18 在「匯出關卡 JSON…」旁新增「隊伍對比」。收集一般單人關卡後，點一下便把本次擷取紀錄帶到目前選取編隊的離線試算，不需先匯出或重新入場。開啟編隊會停止連續轉珠；返回遊戲後仍需自行重新啟動。對比使用編隊配方，沒有宣稱已完整讀回當前遊戲隊員、徽章、HP、技能持續期或異常。

對比頁可直接選光三心三、光 L 心四、光 T 心四等條件。每層分別比較隊長盾、技能盾、日常 HP 倍率及高 HP 救援，列出 HP 容量、已讀攻擊部分、回血後 HP 估值和資料完整性。技能假設施放當回合且就緒，不額外疊加上方手填增益；技能 CD／剩餘回合不會從歷史 dump 當成當前值。

「開啟關卡 JSON」及貼上入口接受匯出的 `PADCheaper-dungeon-report` schema 1，最多 16 MB、100 層。缺失的樓層、敵人及行動保持未知，不把部分資料當成完整結果。尚未收集紀錄時，原生對比按鈕停用。原生傳遞只在記憶體，不寫分享檔或定期 status.json；關閉對比頁後再次點按可讀取最新保留紀錄。

## 換關卡不需重新編譯

新關卡使用新 dump 即可計算；攻略 JSON 從「攻略庫」匯入。同一 dungeon／subDungeon 更新，其餘關卡保留。按「儲存攻略庫」後，獨立以原子寫入方式保存在 `Library/Application Support/PADHelper/dungeon-guides.json`，重開編輯器或程式會載入。儲存失敗只在本頁生效，可重試；不修改隊伍庫、設定或 Auto 規則。

隨版附上 2026-11-01 核對的 GameWith 11 月 Lv5 提示。可匯入新資料取代，或恢復隨版資料後再儲存。格式只含數據及文字，不執行腳本，也不按提示施放技能。新增尚未支援的技能／敵人機制解析才需要程式更新。

最小資料包例子：

```json
{
  "schema": 1,
  "kind": "PADCheaper-dungeon-guides",
  "guides": [{
    "dungeon": 1234,
    "subDungeon": 1,
    "totalFloors": 3,
    "title": "我的關卡",
    "checkedAt": "2026-11-01",
    "sources": ["https://example.com/guide"],
    "identityChecks": [{"floor": 3, "catalog": 98765}],
    "notes": ["通用留技提示"],
    "teamNotes": [{"cards": [14060], "text": "此角色在隊內時顯示的提示"}],
    "floors": [{"number": 2, "text": "此層需要解覺醒，提前預留技能"}]
  }]
}
```

最多 64 關、1 MB。`identityChecks`、`sources`、`notes`、`teamNotes` 可省略；加入敵人配對可避免同 ID 在月份更新或隨機敵人改變後套用舊攻略。`teamNotes.cards` 為隊伍模型最終／所選型態的圖鑑 ID，全部存在才顯示。只有 HTTPS 來源可點開外部瀏覽器。日期和提示內容仍需核對，格式驗證不保證攻略內容正確。

## 7802／5 的對照

[GameWith 總覽](https://xn--0ck4aw2h.gamewith.jp/article/show/61061) 及 [Lv5 詳細攻略](https://xn--0ck4aw2h.gamewith.jp/article/show/565958) 與 dump 的 B6／B12／B17 敵人相符。攻略列出的常見大傷害約 434 萬；dump 另含拖延、低血及暴怒等未定位招式。攻略數值不替換原始定義，也不拿來宣告所有分支安全。

雨龍基本範本在雙隊長盾及 #4 的 35% 盾有效時，基礎 HP 409,219，白哉 HP ×1.5 為 613,829，卯之花 HP ×3 為 1,227,657。B2 假設三敵均存活、同回合各出已讀最大正常攻擊，合計約 637,176，超出日常容量；救援容量可容納這部分，但仍需實際 HP 至少 637,177、技能就緒及行動條件成立。兩側行動尚有未解析效果，這不是整段存活保證。

攻略要求 B9 解覺醒及 B13 解五色不可消。卯之花共用 CD 5；若一層一回合，B9 到 B13 只有 4 次回合推進，要加速、額外安全儲技或另一解除手段。B1／B8 的技能延遲、B3 回復力下降、B17 武裝無效與縮盤也要納入技能安排。B13～15 的高傷變屬招在敵人仍為圖鑑屬性時不可使用，不能寫成固定必開 HP ×3。B16 的 450% 現有 HP 重力也不因 HP ×3 自動變得可承受。

## 計算界線

- 觀察 ATK 與後續樓層推算分開；本次首層推得 25 倍。後續倍率未逐層讀回，可填明確情境倍率。不同 spawn-table 雜湊的舊觀察不提供倍率。
- 複合招保留順序和重複子招；連擊逐下取整，重力依當下 HP；未知機制和先改覺醒／武裝再攻擊保持不完整。
- 減傷取五屬中最低者，離線盾鏈尚未證明與全部原生條件盾取整邊界一致。HP 門檻盾可在連擊途中失效，不判成完整存活。
- 多敵合計假設倒數與分支同時發生，未模擬擊殺、根性、超根性後選招或先制時點。1 回合 HP 技能不保證跨層先制仍有效。
- 心珠回復是無天降公式估值，未宣稱保守下界。技能提高 HP 上限不補血；武裝失效、綁定、毒／荊棘及其他狀態需另算。

`enemyForecastKnown=false`、`survivalAuthorized=false`。此版提供可更新資料的離線對策頁，未接通 Auto 省 T、光 L 心四或三光三心的存活放行。

Node CLI 可在電腦上產生 Markdown／JSON 對比：

```text
node ios/tools/compare_team_dungeon.js DUMP.json FORMATION.json OUTPUT_DIRECTORY [SCENARIO.json] [GUIDES.json]
```

交付包改用 `node tools/compare_team_dungeon.js ...`；模型、預設攻略和來源資料都隨包附上。私有 dump 不放入原始碼庫。實作證據見 [研究記錄](../research/team-skill-dungeon-20261101.json)，檢查結果見 [開發紀錄](development.md)。
