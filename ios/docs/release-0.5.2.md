# PADCheaper 0.5.2-orbs

適用於日服 PAD `jp.gungho.pad` 23.6.0／build 106878，arm64，最低 iOS 15。

修正 0.5.1 在部分 iPhone 剛開始即停止的起點輸入：只送一次按下，接著持續按住，讓遊戲在下一幀選珠。清理輸入後保留真正的停止原因，診斷增加起點 sent／accepted。保留每格交換、放開與輸入還原檢查。

技能規則新增「技能就緒就放」快捷設定。按下後間隔改為 1；連續模式每次轉珠前確認原生技能可用才施放，其他條件與輪替、保留設定仍有效。

## 兩隻白哉輪替

[GameWith 隊伍](https://xn--0ck4aw2h.gamewith.jp/article/show/574233)中的兩隻白哉位於 5、6。PC → 自動轉珠 → 技能規則，依序新增：

| 設定 | 白哉 A | 白哉 B |
|---|---|---|
| 啟用／位置 | 開／5 | 開／6 |
| 輪替組 | 1 | 1 |
| 回合間隔 | 1 | 1 |
| 本場一次 | 關 | 關 |
| 指定樓層／保留至樓層 | 0／0 | 0／0 |
| 其他觸發條件 | 不限定 | 不限定 |

儲存後按「開始連續轉珠」。在兩者正常就緒且沒有額外條件阻擋時，每個轉珠回合只用一個，順序 5→6→5→6。若白哉放在其他格，只改位置；輪替順序按規則的上下排列。冷卻由遊戲判斷，間隔 2 會讓兩條都只在本次第 1、3、5…回合檢查。

其他希望充好就用的技能設「獨立施放」並按「技能就緒就放」。需要變身或繼承額外選擇時仍依原生可用技能及既有選項限制處理。

## 更新與驗證

完整關閉 PAD，在 LiveContainer 的 PAD Tweak Folder 替換成新版 PADCheaper.dylib，移除重複舊版，使用有效憑證重新簽署 tweaks 後啟動。面板應顯示 `0.5.2-orbs`。保留 guest 容器內原 config.json、隊伍庫與帳號檔；範例設定只供首次安裝參考。

新版目前待編譯測試，二進位與 CI 來源會在通過後補入。真機 iPhone 修復及白哉實際技能仍待回報；詳見 [裝置驗收](device-testing.md)及 [驗證記錄](development.md)。
