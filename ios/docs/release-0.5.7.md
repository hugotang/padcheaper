# 0.5.7-orbs

改進形狀求路及敵方暫時變身的整包流程。轉轉盤優先引導至各相位都能保留的形狀位置，主搜尋失敗再按缺項補搜；深入檔可回訪最多兩批被淘汰的分支。全部共用原有時間及步數上限，沒有放寬光 T、心四連、毒或爆彈判定。

使用者的 7×6 雙轉轉盤在 Windows 回歸中，均衡取得 24 步、最低 3 Combo，深入取得 44 步、最低 6 Combo，六相位均有光 T＋心四連。快速仍未達標。一般 36 盤的同源對照，三檔四連達標數由 0.5.6 的 28／32／33 增至 30／33／36，沒有成功變失敗的樣本；難盤可能花更多時間。這是指定樣本的桌面量測，不是保證每盤有解或 iPhone 耗時。完整數據見 [搜尋說明](orb-shape-search.md) 及 [對照報告](../research/orb-shape-results-057.json)。

已確認開場的隊伍遇到原生暫時變身，會核對底層原本角色／武裝後保留流程，其他隊員繼續。受影響位置暫停原形態及未指定角色的技能規則；明確指定當前暫時角色的規則仍可由原生決定是否施放。恢復後接回原技能循環，不重播開場。必要自救技能的條件仍會檢查，不能因施放者變身而忽略；來源不明或實際換隊仍停止。

隊長模式依當下隊長重建目標；手動目標保持原設定並提示暫時隊長的倍率／減傷未被這些目標證明。原生讀取只補充暫時身分資料，沒有強制還原敵人效果。config 格式不變，現有雨龍模板可繼續使用。

Windows 求解器／模型及獨立 oracle 回歸通過；macOS 原生／session／規則／config、iPhoneOS 編譯／簽章、瀏覽器及模擬器 GUI 待本次 CI 驗證。`device_verified=false`。T 字首消六顆的真機根因仍未確定，既有放手盤面記錄保留供追查。

安裝全新 0.5.7 dylib 前停用舊版，再以 LiveContainer 重新簽署並完整重啟。保留原設定、隊伍庫及舊版交付。重啟不會推測本場開場進度，請在新單人關卡驗收。
