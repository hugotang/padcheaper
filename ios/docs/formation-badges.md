# 隊伍徽章資料與分享格式

2026-11-07。徽章選單的資料與離線圖示見 [badge-catalog.json](../editor/badge-catalog.json)。本次查閱 [PADDashFormation](https://github.com/Mapaler/PADDashFormation/tree/fbbafa14ed1364842e783ba4db4680d1b3a8d525) 的公開格式與圖示，來源版本固定為 `fbbafa14ed1364842e783ba4db4680d1b3a8d525`，不是隨網頁更新而變動的資料。原始來源只留在忽略的 `build/research/badge-catalog/`。

選單共 121 項：不使用徽章 0、上游列出的 1–120（不含其已移除的 20），以及月卡分享標記 129。只為能確認的常用類別寫入短名稱，其餘顯示徽章編號與圖示，不猜測數值、觸發條件或合作效果。舊隊伍若保存其他合法編號，編輯器應保留並顯示原編號；本表不是原生可用性白名單。

離線圖集是未修改的 408×9196 PNG，單格 102×76。一般徽章使用第 0 欄、第 ID 列；月卡 129 使用第 1 欄、第 0 列。本次使用日文原圖，沒有截取或重繪遊戲圖案。上游 CSS 雖有 121–126 的預留位置，實際圖集及選單只到 120，因此不製造不存在的預覽圖。授權與歸屬見 [圖示通知](../editor/assets/NOTICE.md)。

PADDashFormation 的 `f[0][2]` 並非每個格式版本都直接等於遊戲徽章編號：

| 版本 | 讀入規則 |
|---|---|
| v2／v3 | 舊 0–8 加 1；9→11；10–12 加 7；13→21；14→10；15–17 減 3；18→129。上游對缺值或未知值預設 1 |
| v4 | 50 表示月卡，轉為 129；其餘保留 |
| v5 | 直接保留分享值；50 已是另一個普通徽章，不能套用 v4 特例 |

129 是上游自己使用的 `1 | (1 << 7)` 月卡標記。其原生玩家資料讀入器先取得 deck 第 5 欄的徽章 ID；有額外月卡隊伍銀行且 ID 為 1 時，才加入第 7 位顯示月卡。因此可以保存及匯出分享值 129，**不能把它直接寫入原生徽章 ID**。月卡資格、有效徽章替代及關卡限制仍須由遊戲確認。

目前的研究只提供選單與分享格式依據；沒有驗證所有徽章的數值／效果，也不代表編輯器中的選擇已套用到當前戰鬥。原生套用與保存範圍另見[原生來源對照](formation-badges-native.md)。完整格式證據、來源雜湊與未執行標記見 [研究記錄](../research/badge-catalog-20261107.json)。本次僅檢查 JSON、ID 唯一性與圖集範圍，未編譯或執行測試。
