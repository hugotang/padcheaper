修正徽章重啟保存、功能關閉後還原遺失與同進化鏈本體技能選擇；新增未通關隊伍 BGM、策略檔案分享／匯入及荊棘 Combo 偏好。編譯與驗證狀態見 [開發紀錄](development.md)，真機驗收仍待回報。

- 自動轉珠頁新增「荊棘盤優先 Combo」開關，預設關閉。開啟時先選較高 Combo，同 Combo 再選較少傷害；首消心四連、HP 足夠與原本目標限制仍須滿足。隨目前隊伍策略保存，也包含於整包 config 匯出。
- 荊棘候選曾參與搜尋且時間尚有餘裕時，補搜零接觸路線；沿用原期限、步數、目標及傷害優先。裝置盤面桌面重播由 2 Combo／13 步改善至 7 Combo／48 步，兩者皆零接觸；這不是 iPhone 量測。
- 最近三次轉珠紀錄保存各自求路耗時、候選數、輪次及深度，便於區分達標短路線與搜尋不足。
- 徽章保存修正 save_decks 請求編號與 serializer 降為 0 的原始選擇判斷；登入後資料延遲、儲存回蓋及關閉外觀功能的還原失敗會保留重試。已被舊版存成 0 的徽章需重新選擇並保存一次。
- 面板新增預設關閉的「未通關也使用隊伍 BGM」，使用已載入的指定曲目，保留原生關卡事件選曲與單人限制，不修改通關旗標。
- 隊伍／關卡策略新增原生檔案分享與 JSON 檔案匯入；普通策略、整包均可分享，匯入先預覽再儲存。詳見 [保存、BGM 與分享](persistence-music-sharing.md)。
