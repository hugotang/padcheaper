# 0.5.29-orbs：手動變身接續、8 人斷線不停、倒數自動開始、重開 app 可轉珠

## 單人開場手動變身後接續

開場變身步驟被敵人延遲 CD 時，手動變身後第一次按 Auto（不論樓層、是否已轉珠）會從變身之後的步驟開始；之後遊戲判定未就緒的開場技能記為略過並繼續，不重試、不停止。一般從頭開始的開場仍在未就緒時停止。

## 8 人其他玩家斷線後繼續

遊戲對 4／8 人使用同一套退出處理（`0x100011BEC`），完成後保留 `0x10000` 標記。0.5.28 只在 4 人讀取退出席位，8 人看到標記即停止（`log/multi_disconnect.txt`：`networkFlags 0x10001`）。現在 8 人同樣讀取退出席位，退出者為其他席位且狀態為已退出／已斷線時繼續；本機連線、計時與盤面檢查不變。3 人輪換機制未改。

## 8 人倒數後自動開始 Auto

策略編輯器新增常駐開關。倒數完成、本機可操作時自動開始本場 Auto；每場最多一次，本場手動停止（含手動開始的場次）後不再自動開始；不入場、不排隊、不重新配對。

## 重開 app 回到中斷關卡可轉珠

恢復中斷關卡時遊戲不會再送出本工具監看的登入回應，0.5.28 因此判定未就緒（`log/solo_relaunch.txt`）。轉珠與原生技能改為只需玩家 ID 一致；隊伍替換、徽章、隊伍儲存仍要求登入。此時進場自動套隊不會執行，恢復的關卡使用遊戲保存的隊伍。

## 驗證

Windows 回歸通過（含 4／8 人斷線模型案例）。session 測試、iOS 編譯與 GUI 見 CI。全部 `device_verified=false`。
