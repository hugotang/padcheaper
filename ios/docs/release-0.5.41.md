# 0.5.41-orbs：轉轉求路修正與單人續玩手動取色

日服 PAD 23.6.1／107553、arm64，最低 iOS 15。本版已獲使用者指示開始編譯測試；完整回歸、iPhoneOS 建置及交付結果仍在確認中。未完成前不視為已交付，真機狀態維持 `device_verified=false`，詳見[開發紀錄](development.md)。

- 修正單轉轉失敗候選的保留：同樣完成心珠目標時，四色進度不再被後來三色候選覆蓋；完整目標與安全條件仍優先。
- 普通多色补搜保留原有完整搜尋方向，另在既有回訪中依起手考慮荊棘阻擋，避免只靠首消提示漏掉連鎖可能。原地可匹配的荊棘珠仍保留；未知傷害預算時仍禁止接觸其他荊棘，起手持有荊棘珠仍可。
- 多色轉轉及單次取色重用相同布局的相位評估，維持搜尋預算、完整目標與逐路重播。是否提升兩份原盤的解出率，由本輪實際量測記錄。
- 支援 3 人協力原生「單人續玩」中明確按下的本次取色。續玩使用原生移動鐘；連線 3 人保留移動／本機回合雙鐘。來源、操作權、本機隊伍、輸入及持珠變動即停止舊操作。
- 未嘗試取色時直接說明模式、鎖珠、荊棘或時間限制。3 人／續玩 Auto、4／8 人取色、帶鎖／荊棘連撈、換隊或修改計時均未擴充。

原盤與既有失敗路線的證據見[四轉轉調查](solver-four-spinners-2026-11-07.md)、[單轉轉調查](solver-single-spinner-2026-11-07.md)。新增案例涵蓋原盤與變體、取色、附加資料、相位結果及操作撤銷；寫入案例不代表已通過，真機取色與多人同步仍待驗證。
