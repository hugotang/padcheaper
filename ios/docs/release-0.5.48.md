# 0.5.48-orbs：單人荊棘取色與消 T 徽章診斷

2026-11-15 更新：本批已通過 [CI 162](https://github.com/hugotang/padcheaper/actions/runs/43677924009) 的完整回歸、建置、簽章與四份 iPhone GUI，交付為 0.5.48-orbs。完整結果見[驗證收據](../research/verification-0.5.48.json)。真機取色／回血與徽章歷史漏算根因仍未驗證。

目標為日服 PAD 23.6.1／107553，arm64、iOS 15.0 以上。本檔為建置來源說明，編譯測試與交付結果見[開發紀錄](development.md)及交付附帶的 verification.json。

- 新增隨策略保存的「荊棘盤允許取色」，預設關閉。普通單人的單次及 Auto 可在有荊棘的盤面嘗試最多六次取色；沿用上方「心三連即可」／心四連政策，所有終盤轉轉相位都須符合回復條件。
- 傷害隨珠子與每次目標接觸計算；等待不重複計傷，放進轉轉再碰入同一顆荊棘仍會再計傷。移動及等待期間按當前 HP、有效上限、待結算傷害與剩餘路徑重新檢查，不預支消心回血；資料變動或預算不足時停止並放開。
- 補齊取色路線的荊棘傷害／接觸次數重播及執行診斷。未知 HP 只允許零傷害接觸，鎖珠及多人荊棘取色仍不支援。詳見[荊棘取色設計](orb-thorn-fishing-2026-11-15.md)。
- 消 T 徽章新增逐效果加算證據，保留零值原生描述，區分未提供加算與未證明觸發。原 log 的 7＋隊長 6＋徽章 2 若均有效應達 15；歷史徽章為何讀到 0 仍需新裝置 log，沒有硬加 2 或宣稱根因已修復。取色未找到最少次數時改為 null，避免把內部 sentinel 7 當成必須取七次。詳見[徽章調查](orb-combo-badge-2026-11-15.md)。

回復量由使用者確認；離線與模擬器結果不能代替實際取色時序、傷害／回血及原盤可解性的手機驗證。3P／ThreeSolo 原有手動取色範圍、4／8P 限制及手動 CI 維持。
