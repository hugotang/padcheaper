# 0.5.33-orbs：求路失敗原因、轉轉診斷、只驗 iPhone GUI

包含 0.5.32 的單人轉轉撈珠，並修正停止提示與診斷。搜尋策略、敵人對策門檻與多人限制維持原有行為。

## 停止原因

- 雨龍 6×5 盤面被要求首消 13 Combo 時，顯示需求及盤面最多 10 Combo，不再泛稱珠數不足。一般單人仍不計隊長／技能加算，因此可能停止於遊戲中手動可突破的盤面。
- 分別指出哪一色獨立形狀缺珠、不可消、精確珠數與最少消除規則衝突、組数／色數／Combo 上限。轉轉顯示至少一種色序未通過，避免將保守判定說成完全無解。
- 已知「Combo 以上吸收」顯示目前不支援；求路內部錯誤、設定校驗、候選搜尋失敗各自說明。搜尋紀錄保留與畫面一致的原因。
- 分開開始逾時、操作時間不足、換珠確認逾時與交換結果不符；放手檢查指出失敗項。等待穩定狀態逾時不再直接歸因轉轉。

## 轉轉與測試

- 全鎖盤面顯示可穿過轉轉格；撈珠診斷顯示包含等待一圈的執行上限，文字 log 補上轉轉倒數及是否讀取成功。
- 依使用者要求，CI GUI 保留 iPhone Scene／legacy 各初次與重開，共四輪；移除 iPad 自動驗證。編隊瀏覽器檢查仍執行。

## 驗證

Windows 回歸通過。Objective-C、arm64 編譯及 iPhone GUI 待本版 CI；`device_verified=false`。撈珠實際取色、倒數與等待時序仍待實機確認。
