# 0.5.47-orbs：武裝滿蓄替代施放與荊棘心三連

目標為日服 PAD 23.6.1／107553，arm64、iOS 15.0 以上。本檔是建置時的來源說明；編譯測試結果見 [開發紀錄](development.md)，交付時附 verification.json。

- 循環新增「本體優先，滿蓄改用武裝」來源。原生可選本體時仍用本體；只能用滿蓄武裝時，以獨立武裝結果記錄，不冒充本體規則或必要技能已完成。技能後重新讀盤及核對狀態，保留原生可用性、來源及防重複檢查。雨龍範本已更新；既有裝置策略需重新匯入或手動選新來源。詳見 [武裝滿蓄說明](orb-assist-overcharge-2026-11-12.md)。
- 新增可隨策略保存的「荊棘盤心三連即可」，預設關閉。回復足夠的隊伍可開啟，允許首批有效三顆以上心珠，仍逐個轉轉相位核對。完整拖珠傷害加待結算傷害必須低於目前 HP，不預支回血；消毒及指定心四連目標保持獨立。
- 手動轉一次也保存求路當時的 HP、待結算傷害和最多額外傷害；離場後的即時零值不會覆蓋當次證據。

取色搜尋仍不支援荊棘盤，多人仍避免有傷害的荊棘接觸。原 log 缺少完整 HP 與實際回血資料，不能宣稱新選項必然解出原盤；真機武裝效果及回復能力仍待驗收。8P 固定技能來源、開場精確技能及多人操作範圍維持原設定。
