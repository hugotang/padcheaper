# PADCheaper 0.5.4-orbs

適用日服 PAD 23.6.0／106878、arm64、iOS 15 以上，限定單人。

## 本次變更

- PC 浮動入口旁新增「轉一次」及「開始自動」，操作後可直接停止；短訊息顯示求路／完成／停止原因。轉一次沿用目前目標與品質，自動讀盤、求路及執行一條路徑；連續模式沿用技能規則。
- 支援經檢查不含編隊指令的原生事件腳本，演出／BGM／文字事件不再一律阻擋套隊；真正的 `party` 指令及無法核對的腳本仍拒絕。診斷拆開各種阻擋原因。
- 還原一格後，暫時的腳本執行／來源讀取失敗不再清掉其餘還原紀錄。還原先停止自動操作，並顯示剩餘及失敗位置；見 [套隊與還原依據](scripted-team-restore.md)。
- 修正 30 fps 長路徑因渲染／讀取耗時多等一幀，可能在約 39 步碰到 4 秒上限的問題。仍逐步確認交換，保留 65 ms 間隔及原生時間限制。
- 停止原因分開顯示執行逾時、手動操作、盤面限制及遊戲結束拖珠，並記錄本次執行時間。新求路清除舊進度。
- 待命隊員通過原生就緒判定後，清除殘留的舊技能選擇，再啟動當前技能。只還原原生預設選擇，不改充能。
- 規則診斷顯示位置，原生拒絕保留當時的充能、本體／武裝技能 ID、CD 及進化階段，區分冷卻不足和冷卻已足但原生仍拒絕。停止後仍可複製完整原因。

夜一與ユークス＆ミヤ的漏放回報尚不能只憑舊 log 判定根因。新 log 的位置 3 在其他技能後均重查；複製時充能 5 晚於規則判斷，可能在中斷轉珠後才充滿。新診斷用於確認這個差異，不繞過遊戲的不可用判定。詳見 [問題與原生依據](orb-skill-selection.md)。

## 更新及核對

完全關閉 PAD，在 LiveContainer 的 PAD Tweak Folder 替換 PADCheaper.dylib，重新簽署 tweaks 後啟動；面板應顯示 0.5.4-orbs。保留原有 config.json 和隊伍庫。

用目前六個位置每回合獨立施放的設定，核對長路徑能完整結束並進到下一回合，位置 3 在本體 CD 足夠時接上施放。若仍被略過，複製診斷中的 Skill decisions 和 Orb execution；它們會保留拒絕當時資料。再核對手動停止、選擇框及同回合不重複。

在原先 3600 秒關卡分別核對新入場套隊與操作階段手動套隊；用「全部還原」確認六格均恢復。若未完成，複製 `Battle:`、`Entry result:`、`Battle script:` 及 `Battle restore:`。舊 log 不能區分有無編隊指令，不把本次相容擴充當成所有關卡已通過。
