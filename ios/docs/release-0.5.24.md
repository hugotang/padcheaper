# 0.5.24-orbs：B5 兩技、B6 條件式準備與改盤後救援

攻略模式的 B5 改為優先火奈 #4→赤龍女 #6，備案 #4→#1；火奈不就緒時才考慮珠數可行的單赤龍女。這能減少先補珠、後改盤覆蓋效果，以及為救 B5 提早用掉尾層 #2 的機會。每次技能仍依原生回報重讀。

B6 不固定每次轉 1C。火奈未就緒、雙轉色技差一回合、保留攻擊色珠會比現盤及目前可用轉色更多時，才優先準備一次三珠首消，再等實際吸收消失後迦具土 #2→巴爾丁 #3；兩技現在已可用就直接雙開。僅本杯一回合 5 Combo 吸收、至少 15 秒及可驗證盤面適用，沒有合格準備路徑則停止。

修正救援清單在火奈改盤後仍停在末尾，漏掉先前因珠數不足而略過的轉色技能。確認技能完成後重新搜尋，保留序列進度與防重複施放紀錄；停止接續、CD與未確認回報的限制維持。診斷同時保存首次及最新卡住盤面。

活動求路在已有達標解時，以原本剩餘搜尋時間嘗試最多兩個有利的攻擊色橫排，保留原解，所有候選仍須符合原12連與Combo條件。B1首消Combo與準備回合的求路條件不變。五份0.5.23紀錄的十筆輸出盤回放中，八筆維持、兩筆B6改善，其中一筆相對輸出指標約增加12.3%，但路線由32至43步；不是實際傷害或穩定通關保證。
