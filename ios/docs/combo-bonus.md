# 一般單人 Auto 的加 Combo 證明

2026-11-05 源碼變更，尚未編譯或執行測試。它只降低一般單人 Auto 為敵人「N Combo 以下吸收」加入的臨時條件，不改使用者儲存的 Combo 目標、手動轉一次或 8 人規劃。

## 計算與限制

所需首消為 `max(1, N + 1 + 有效減算 - 可確認加算)`；有原 Combo 目標則再取較大值。多敵人取最大門檻，有效解吸收則撤下臨時条件。「Combo 以上吸收」仍停止，沒有最高 Combo 證明。

只使用原目標必定達成的觸發條件。只要用了隊長／徽章加算，顏色與消除目標一併限制在首消；直列目標另要求實際消除群組只佔一列，不能有被併入消除的同色支線（`0x1005F7954` 的 `+601619` 判定）。後續連鎖或隨機天降不作證。重疊目標不能當成不同消除組數相加，指定同色多組則按獨立組數要求。條件不能證明時 credit 為零，讀取不完整也不猜測。

| 原生效果 | 本輪可證明的條件 |
| --- | --- |
| type 219 | 指定集合中任一色，連消至少指定顆數 |
| type 192 | 指定集合每一色，均連消至少指定顆數 |
| type 194 | 達成指定色數；五屬只計目前未綁定成員可攻擊屬性，心另計 |
| type 206 | 指定色組數，允許重複色；遇 signed 負色值終止列表 |

| type 271／徽章 27 | 指定覺醒全部觸發；本輪支援四顆 27/96、方塊 48/109、L 60/108、十字 78/110、T 126 |
| type 285／徽章 30 | 指定直列覺醒 149–153；未支援 44／59 的條件 |
| type 280／徽章 28 | 上述已支援覺醒至少觸發一次；目前只計一次加算，不外推重複倍率 |
| 有效技能調整 | 目前 signed8 正調整，扣抵獨立減 Combo |

覺醒供應者按當前本體已解鎖、超覺醒／同步條件、有效武裝及追加覺醒讀取，排除綁定、封覺醒及關卡禁覺醒。形狀覺醒需要相符的攻擊屬性。動態隊長賦予覺醒暫不提供證明；未知武裝變體也不提供覺醒 credit。未列出的隊長／徽章条件、Combo 珠及天降不計。每效果超過 20 或模型加算總額超過 100 時不給 credit。
