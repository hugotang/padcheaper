# 盤面效果適配

2026-10-29，接續夜一轉轉及「雲、封條、暗闇等盤面全部適配」的要求。本頁描述 `0.5.3-orbs` 的新增能力；已交付的 `0.5.2-orbs` 沒有這批能力。Windows 求解器／model 與 CI 59 的完整原生、arm64 iPhoneOS、瀏覽器及四份模擬器／重啟檢查通過，三種尺寸的完整效果畫面已檢視；來源與雜湊見 [開發紀錄](development.md)，真機驗收仍待完成。

## 處理範圍

0.5.5 增加荊棘路徑傷害預算、改尺寸後的轉轉保存範圍、指定不可消珠色及原停止原因保留。最新驗證以 [開發記錄](development.md) 為準，以下表格為目前來源行為。

目標仍限日服 iOS PAD 23.6.0／106878、LiveContainer arm64、單人 6×5／7×6／5×4。遮蔽效果使用底層真實珠型，移動限制則加入搜尋及原生輸入前檢查，不改遊戲珠型、效果旗標、傷害或計時。

| 狀態 | 求路與執行方式 |
|---|---|
| 雲 | 讀取矩形覆蓋區及持續回合，顯示「雲」；可在雲下正常規劃及移動 |
| 普通暗闇 | 讀取真實珠色，顯示「闇」；允許原生交換後清除普通暗闇旗標 |
| 超暗闇 | 保留真實珠色、持續回合及旗標，顯示「超闇」；資料隨珠交換 |
| 封條 | 合併橫列／直行遮罩並核對每格旗標；起點及全部路線都避開封條 |
| 固定起點 | 只能從原生指定格開始，預覽顯示「起」；接受按下後的原生暗化標記清除 |
| 鎖珠／強化／弱化 | 支援已知旗標及 −1 至 1 的有限強化值，顯示鎖、+、−；完整保留隨珠資料 |
| 邪魔 | 可交換與消除，計入基本 Combo；不算火／水／木／光／暗／心的顏色目標 |
| 一般毒 | 可以留盤及移動，未消毒不會爆炸。預設避免首批及盤內連鎖消毒；0.5.11 可為回復足夠的隊伍開啟首消心四連消一般毒政策 |
| 猛毒 | 可以留盤及移動，仍禁止首批及盤內連鎖消除；一般毒選項不放行猛毒 |
| 爆彈 | 必須在首批消除全部爆彈；只在之後落下才成組，仍視為首批未消爆彈 |
| 刺珠 | 可抓起及移動；造成傷害的目標接觸須有首消心四連，HP 大於待結算與整條路線傷害上限；不預支回血／抗性 |
| 釘珠／Combo 珠 | 保留旗標並顯示「釘／C」，照普通幾何消除；不估算釘傷害或額外 Combo |
| 不可消 | 相應珠色不參與消除，首批及盤內連鎖都套用；仍可移動、參與規則判斷及顯示「禁消」 |
| 最少消珠 | 套用原生 3–7 顆最短直線，以及兩個欄位較高的已標記相連群組門檻 |
| 轉轉 | 支援已核對位置與共用色序的單格／多格轉轉，所有可能色序都須達標，路線避開每一個轉轉格 |

毒／爆彈檢查是目前盤面在已建模消除規則下的限制，不是存活保證。0.5.5 僅估算荊棘傷害上限，不估毒免疫、回復量或隨機天降。0.5.11 的一般毒選項採用使用者確認的隊伍回復能力，只有全部相位均有首消、恰好四顆直線心珠組才放行；猛毒及爆彈限制不變。搜尋時間有限，未找到可執行路線不等同盤面無解。多相位轉轉在每個候選之間檢查時限；單個候選仍完成全部相位評分後才可保留，未量測真機耗時。

未知珠型（包括 native type 10）、未分類旗標、無法校驗的受保護值、未知尺寸、特殊操作模式或不一致投影仍會停住。這份已知效果清單不等於日後任何新增機制都自動相容。

## 夜一與轉轉

改尺寸可能保留舊橫向 7 格、縱向 6 格的轉轉位置與格數。0.5.5 先核對全部保存位置，再裁切到目前尺寸；只有盤面外的轉轉不影響移動。數量不符、無效位置／週期／色序仍拒絕，`Spinner read` 列出具體原因與原始值。

夜一 #14055 的技能 `64863` 含 type 207 子技能 `64865`，參數 `[4,50,0,0,0,0,0,1]`：1 格、4 回合、0.5 秒週期。這解釋了為何舊 `0.5.2` 不能把「夜一就緒就放」直接當作可持續自動操作的設定。舊版建議已更正於 [雨竜／白哉](uryu-byakuya-0.5.2.md)。

原生更新使用共用倒數；每次更新，已靜止且未上鎖的轉轉格沿同一色表各前進一色。搜尋保留格子之間的相對色序，枚舉共用相位，最多 10 種。鎖定的轉轉珠保留實際顏色，但所在格仍不可穿越。自訂色表可含邪魔、毒、猛毒及爆彈；若變到特殊珠會清除強化／釘珠／Combo 旗標，先等待這些資料已歸零才接受模型。

每條候選路線都按全部相位重算首批與盤內連鎖；Combo、消珠與每項目標顯示最低值，毒消除／首批未消爆彈顯示最高值。相鄰轉轉可能把獨立 T／L／四連黏成大團，因此也在檢查範圍內。沒有按時抓色、暫停轉轉、從轉轉取色或等待特定放手時機。

讀盤穩定、求解期間、執行前及每次原生交換後都允許共用相位推進，但 token、非視覺旗標、強化、幾何、遮罩、不可消及起點限制仍須一致。只有某格獨自改色、換 token、改鎖或換位置等情形均取消舊路線；已持有自己的珠時沿用原生放開流程。尺寸、帳號、場景及多人邊界保留既有停止限制。

## 技能、補心與預覽

`obstacle` 保留舊值，增加 `jammer`、`poison`、`mortal_poison`、`bomb`、`cloud`、`tape`、`blind`、`super_blind`、`nail`、`thorn`、`fixed_start`、`combo_orb`、`match_rule`。它們只決定使用者指定的技能何時嘗試，不自動選擇解法。技能完成後重讀；已有的群組、樓層保留、本場一次及必要技能規則照常生效。

缺珠門檻採全部相位的最小／最大珠數：全部不足才觸發，全部足夠才略過，跨越門檻則回報無法確認並停止連續流程。低血補心也取心珠數的最小值，不可消心珠不算可用；最少直線或群組數高於 4 時，獨立心四連要求直接阻擋。心珠數足夠僅代表可搜尋，仍須全部相位都完成要求。

預覽區分火、水、木、光、暗、心、邪、毒、猛、爆，顯示鎖／+／−及上述效果。滑桿重播時，珠上的效果隨珠交換，雲、封條、轉轉及起點留在格子上；普通暗闇在走過的交換處清除。毒／爆彈不合格時仍可查看候選，執行按鈕及後端入口都拒絕。診斷另列遮罩、色表、相位數、持續時間、消除門檻和毒／爆彈計數。
