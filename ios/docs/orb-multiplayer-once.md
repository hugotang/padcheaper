# 3／4／8 人「轉一次」— 0.5.12

2026-10-31，新增使用者明確點擊的多人「轉一次」。本功能收齊於 0.5.12，已授權編譯測試；LiveContainer／Dopamine 真機及多人同步尚未驗證。0.5.11 不含此功能；建置與測試結果以 [開發紀錄](development.md) 為準。

建置並完成驗證後的操作：先設定「高 Combo」或「指定形狀」及求路品質，返回遊戲；若浮動列已收合，先點 PC 展開。等自己的盤面穩定、放開手指後按浮動「轉一次」。它立即核對本機操作窗口，讀盤、求路、執行一條路徑、放手後停止。錯誤窗口的點擊直接取消，不會排隊等到下一回合。收合只隱藏快捷列，執行中留下的單顆按鈕仍可立即停止；收合功能同樣由 0.5.12 提供。

多人閒置時的浮動短提示優先顯示目前能否轉一次及等待原因，完整訊息保留模式、席位、回合與剩餘時間。總開關／前景未就緒、其他玩家回合、同步、開始倒數、時間不足及放手未確認時，不會顯示可開始新一次；舊的停止原因仍保留於轉珠面板、診斷及狀態的 VoiceOver 文字。換回合恢復可用不會自行展開或開始工作。這批狀態整合案例納入同一批回歸，實際結果见開發紀錄。

| 模式 | 原生分類／selector | 本機操作條件 |
|---|---|---|
| 3 人協力 | mode 7／multi 1 | 本機席位有效、顯示自己的隊伍，且 turnSerial % teamCount 等於本機席位 |
| 4 人對戰 | mode 11／multi 1 | 本機席位與盤面一致，倒數已完成、整場計時有效且未結算 |
| 8 人對戰 | mode 10／multi 1 | 本機席位與盤面一致，倒數已完成、整場計時有效且未結算 |

4／8 人各自操作本機盤面，不使用 3 人輪流回合的餘數判定。mode 7 中剩下兩席仍使用 3 人規則；這不表示支援另一種 2 人協力模式。其他模式／selector 組合繼續拒絕；7／10／11 的 selector 歸零也不會被當成單人。分類在同場改變時，必須觀察到離場才清除限制。

本批保留以下範圍：

- 多人使用 Combo／手動形狀目標與原有求解器。隊長／助人條件尚未驗證，選擇該模式會明確拒絕，不自動改成 Combo。對戰分數、天降、加算及傷害不在預測範圍。
- 「讀盤並求路」可唯讀預覽目前可操作的本機盤面；多人預覽的「執行一次」停用。必須再按浮動「轉一次」，以新讀盤建立一次意圖。
- 連續模式、技能規則、開場、隊伍替換、BGM 戰鬥寫入及計時修正仍限制單人。沒有多人 allow-all 開關，也不編輯或重送封包。
- 保留珠型、物件池、幾何、封條、轉轉、固定起點、不可消與毒／爆彈等校驗。多人不讀取單人 HP 推導，求路及逐步輸入拒絕造成傷害的荊棘接觸；站在已持有的刺珠格不視為再次接觸。
- 求路與執行會計入可用轉珠時間、多人倒數、0.35 秒準備、逐幀步距及放手餘裕；執行維持 4 秒上限。剩餘時間不足時停止，不延長原生時間。

## 回合與輸入邊界

每次意圖、預覽及原生手勢綁定同一場戰鬥、wave、本機席位、顯示隊伍、回合序號與盤面大小。4／8 人額外綁定整場計時的起始 epoch；剩餘秒數自然下降不算換回合。3 人第一次交換會由原生暫停選珠前的回合倒數，因此持珠後接受該暫停狀態，繼續受普通轉珠計時限制；未持珠時暫停倒數不允許新開始。

按鈕當下會重新讀取狀態，取消條件包括換回合／席位、PASS 或同步、斷線、其他玩家視角、盤面改變或縮放、手動觸碰、離開前景與時間不足。求解工作取消後，舊回傳無法復活意圖。每一幀送出 hold 前重新核對；已中止路徑不接下一盤。

native engine 要先收到這一次點擊的 arm，才允許一次 began。起點尚未接受時，只可在原起點續送 held，不能再 began 或換起點。獨立保存起點 token，不改寫盤面限制欄位。原生確認選珠後才持有該 token；停止撤銷後禁止 hold，只保留同一窗口、同一 token 的 release。放手未被接受時可重試；回合／場景／連線改變便撤銷所有權，不把清理輸入送到新窗口。

只有原始 drawFrame 執行期間，global input pointer 暫指向私有 manager。`finishInput` 恢復原始 pointer，真實 UIKit 觸控紀錄不被覆寫。沒有直接交換盤面、呼叫 bank getter、network pump、sender 或計時修改函式。原生 `0x10060D1F0` 自行接受輸入，3 人的普通 native dispatch 在其後按自身規則走 sender。這是靜態呼叫流程證據，不能替代雙端同步實測。
