# 0.5.40-orbs：五色轉轉補搜、3 人手動取色與每隊徽章

日服 PAD 23.6.1／107553、arm64，最低 iOS 15。使用者於 2026-11-07 明確要求「編譯測試」；本版合併 `477ccd8` 與 `79da04d`，本文件先記錄候選來源，完成結果另記於 [開發紀錄](development.md)。目前尚未完成本版測試或交付，真機狀態為 `device_verified=false`。

- 五色目標可搭配心三連及轉轉使用缺色引導、保留不同搜尋分支與剩餘時間補搜。普通路徑仍避開轉轉格，按每個可能相位驗證完整目標；有限時間內未找到路線不代表盤面無解。
- Fishing 支援單人轉一次／連續，以及明確點擊的 3 人協力本次轉一次。3 人取色規劃共用原期限，普通搜尋先保留部分時間給取色；等待、交換、座標轉換及放手持續檢查原生移動／本機回合雙鐘、回合、隊伍、輸入及持珠身分。
- 3 人 Auto、4／8 人取色及 3 人斷線後單人續玩取色不在本版範圍。換隊仍限單人；本版沒有自動進場、排隊、再戰或封包／計時器修改。
- 六人編隊下方可選擇並保存每隊徽章，附離線圖示；支援切隊、複製、撤銷、分享與完整策略同步。舊版分享映射及未收錄的合法編號保留，晚到的儲存回覆不覆蓋新草稿。
- **徽章目前保存的是隊伍選擇，仍需在遊戲內選用；套隊不自動切換徽章，隊伍試算也尚未計入其效果。**
- 新增跨盤面尺寸、六色、形狀／消除門檻的系統案例，以及取色雙鐘／換手／持珠變更、終盤放手及徽章保存／分享／手機版面案例。本輪將執行完整測試與 iPhoneOS 建置，不能以案例已寫好或舊版 CI 代替本版結果。

求路修改與原盤證據見 [五色與轉轉](solver-colors-spinner-2026-11-07.md)、[原生規則矩陣](solver-native-rules-2026-11-07.md)。徽章資料與限制見 [每隊徽章](formation-badges.md) 及 [原生有效徽章來源](formation-badges-native.md)。多人同步與真機取色時序仍需裝置驗證。
