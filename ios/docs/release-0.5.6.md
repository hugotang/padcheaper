# 0.5.6-orbs

新增可匯入／匯出的「隊伍＋開場流程＋技能循環＋盤面目標」config，附石田雨龍 × 白哉四連／心 L 兩種模板。入口：自動轉珠 → 隊伍／關卡策略 → 貼上 config → 驗證並預覽 → 儲存並選用。詳見 [格式與使用方式](team-plan-config.md)。

開場按原生確認逐步前進，核對本體／武裝、技能 ID 及變身後圖鑑編號；停止後保留本場進度，不重播未確認技能。循環可限定本體／武裝、指定技能及至少珠數；雨龍範本要求至少九光，卯之花處理暫時覺醒無效或光／心不可消。隊伍和策略以同一次 config 儲存提交。

轉珠新增放手前實際盤面驗證與最近三次實際路徑紀錄，下一次求路不再蓋掉先前執行盤面。毒盤停止列出讀盤時毒／猛毒數量；候選安全評分明確標示僅代表候選路徑。

使用者兩份停止 log 均未送出轉珠。第一份缺心四連；第二份白哉後仍有 19 毒。T 首消連六顆的真機根因尚未確定，不能聲稱已修復；新增 1,268 種 T 邊界及轉轉測試通過，新紀錄用於追查下一次發生時的實際盤面。放開已持有的珠無法撤回已走步驟。

本批 Windows 求解器／模型測試已通過，macOS／iOS CI 待完成；真機開場、技能效果及結算仍待驗收。`device_verified=false`。單人限制、禁止確定性消毒、荊棘 HP 預算與 4 秒操作上限保留。

安裝時使用全新 0.5.6 的 dylib，停用舊版再以 LiveContainer 重新簽署。保留舊交付可回退；新 config 請先備份，避免用舊版覆蓋新格式。
