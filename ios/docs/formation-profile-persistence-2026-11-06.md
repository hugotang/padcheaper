# 手動潛覺修改在重新選用完整策略後看似消失

2026-11-06，使用者回報已儲存的潛在覺醒，在重開遊戲或更新 tweak 後只剩匯入 JSON 時的設定；補充可能曾再次儲存／切換「隊伍／關卡策略」。本輪以 0.5.37 交付來源 `8fe243d` 及目前來源 `2cb8702` 做靜態追查，找到符合症狀的選隊／配裝不同步問題。沒有讀取使用者手機的設定檔，因此尚不能確認其遺失時的實際操作順序或修改版是否仍在容器內。

## 已定位的行為

- [隊伍儲存](../src/PHRuntime.m#L214) 把新的隊伍庫放進 `config.json.formations`，原子寫入成功才回報成功；也會寫舊格式備份。潛覺是隊伍資料的一部分，這條路徑沒有單獨丟棄它。
- 完整策略另有 `orbProfiles.profiles[].formation`，仍是匯入時的配裝快照。隊伍編輯儲存不會更新這份快照，也沒有記住策略與隊伍 ID 的關聯。
- [策略儲存](../src/PHRuntime.m#L1193) 每次收到 `orbsProfiles`，只要所選策略包含 `formation`，便呼叫 [PHOrbFormationsSelectingProfile](../src/PHOrbProfiles.m#L293)。即使只是再次儲存同一策略、修改名稱或「開始時自動配對」也會走這條路徑。
- 選隊函式按整份隊伍與策略快照完全相等來找隊伍。修改過任何潛覺後便不再相等；已有原配裝就選回它，否則新增一份原配裝並選用。原修改版仍保留在 `teams`，函式沒有刪除／覆寫它。隊伍庫滿 64 份時則拒絕儲存，沒有先刪隊伍騰位。
- [隊伍選單](../editor/editor.js#L117) 只用隊伍標題顯示選項；兩份配裝標題一樣，外觀上難以辨認已換成另一份。下一次入場套隊也使用新的選取，因此不只是畫面顯示差異。

以下是依來源推導的最小觸發序列，**尚未執行新增重現案例**：

1. 匯入雨龍完整策略，隊伍 A 的第三格潛覺為 `[48]`。
2. 在隊伍編輯為第三格新增防坐，儲存成 `[48,11]`；目前選取仍是 A。
3. 完整策略的配裝快照仍為 `[48]`。
4. 打開策略並按「儲存並選用」；找不到完全相等的原配裝時，新增同名隊伍 B，第三格為 `[48]`，改選 B。
5. 再開隊伍編輯／重開遊戲，看到 B 的 `[48]`；A 的 `[48,11]` 仍留在隊伍庫，除非另被刪除或覆寫。

## 與更新／重開的關係

[啟動載入](../src/PHRuntime.m#L235) 優先讀 `config.json` 的隊伍庫及選取，沒有按版本號重新灌入完整策略；`PHReloadConfig` 也沒有呼叫上述選隊函式。單純重開在有效設定檔下會保留最後一次選取，不會自行同步 JSON 配裝。

`PHOrbFormationsSelectingProfile` 自 `4110f59`（2026-10-29，0.5.6 完整策略功能）加入後沒有修改。23.6.1 位址遷移 `4396f30` 只調整這部分的資料 target 相容／匯出值，沒有改隊伍儲存或選隊邏輯。因此有明確證據的觸發是重新儲存／選用完整策略，不能歸因為 23.6.1 或 0.5.37 新增的潛覺欄位失效。

此不同步不限潛覺；任何令整份隊伍不同的等級、加值、超覺醒、配裝或標題編輯都可能出現。完整策略匯出也仍使用策略內的快照，不會自動帶出隊伍編輯後的配裝。

## 本輪來源修正（尚未編譯測試）

使用者再確認確實產生多份同名 config，要求先修正。本輪已修改來源；以下是新行為，尚未建置、執行新增測試或交付。

- 完整策略新增本機 `formationID`，指向隊伍庫穩定 ID；新增／複製的策略未明確指定既有隊伍時建立自己的配裝，不按同名或本體編號共用。同一策略再次儲存不重新灌入匯入快照。此欄位限完整策略，通用／8 人活動不接受；portable team plan 匯出仍維持原 schema，不輸出本機 ID。
- `PHConfigurationSavingFormations` 與 `PHConfigurationSavingOrbProfiles` 產生完整新設定，不直接改來源；Runtime 原子寫入同一 `config.json` 成功後才發布隊伍、策略與成功回執。潛覺、等級、加值、技能等級、覺醒及標題同步到使用該隊伍的相容策略；本體／武裝 ID 和 ordered opening 保持核對。
- 策略編輯器送出開啟時的版本與每次獨立 request ID；較新的隊伍配裝優先，並用相應寫入回執核對實際保存結果。若其他操作改了策略選取、規則等內容，拒絕舊頁面覆蓋並提示重開；既有畫面值相等不能冒充此次寫入成功。
- 舊資料只在唯一完整配裝能對上、沒有另一相容候選或未綁定的相同策略時遷移。已有原版／修改版同名配置時，不猜選也不合併／刪除；策略頁「使用的隊伍」提供明確選擇。隊伍編成及策略選單均加上「同名 1/2、2/2」等區分，實際以 ID 選隊。
- 原隊伍刪除或更換本體／武裝時保留策略上最後一份相容快照和失效連結，重新選用會要求選回相容隊伍，不能偷偷新增原配裝；未選用的失效策略不阻擋其他策略。明確刪除／重新匯入策略可以使用新匯入的配裝，舊隊伍仍保留。若明確讓兩個策略使用同一隊伍，其配裝修改會一起同步。
- 隊伍庫滿 64 份仍可更新／選用既有綁定隊伍，需新增第 65 份則整筆拒絕。匯入策略保留獨立 `eightAutoStart` 設定；8 人活動選用不替換隊伍，未修改任何遊戲資料／戰鬥操作限制。

既有已交付版本仍有原問題。新版本到裝置後，可先在「隊伍編成」逐份查看同名隊伍的潛覺，再到策略的「使用的隊伍」選回修改版並儲存。沒有讀取手機資料，不能保證某份實際檔案仍在；不自動清理同名項。
