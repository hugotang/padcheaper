# 0.5.25-orbs：B6 準備失敗退回輸出、求路加速與轉珠頁改版

## B6 優先準備

活動 JSON 開啟 `preferBeforeOutput` 時，B6 會先嘗試一回合三珠準備。0.5.24 若這次準備求路在限時內找不到合格路徑，Auto 會直接停止，即使現盤用 #2 或 #2→#3 原本可以輸出。0.5.25 改為退回攻略決策直接輸出；同一回合不再以較小預算重試準備，這次失敗也不記成「輸出失敗」的首次卡住紀錄。優先準備的搜尋時間由最多 150 ms 改為該層預算的一半（至少 150 ms，仍限 12 步）。非優先的準備流程不變。

已有解時嘗試的攻擊色橫排候選，0.5.24 第一色會用掉全部剩餘時間，第二色幾乎不會執行；現在兩色平分剩餘時間，總時間不變，最終仍按原條件與排序比較。

## 求路加速（結果相同）

- 交換兩顆同色珠時盤面不變，直接沿用上一步的評分。
- 每層去重改用固定容量的表，不再每次配置記憶體。
- 非活動模式下，最佳路線已安全、達標、無荊棘傷害，且 Combo 與消珠數達理論上限時，不再搜尋更長的路徑。

Windows 求路回歸與 0.5.24 對照：每個測試盤面的路線、步數與評估節點數完全相同，耗時約快 4–16%。

## 轉珠頁

- 狀態、盤面預覽與 8 人進度摘要（樓層、回合、技能序列、等待確認的技能、留珠準備、最近卡住與上次停止原因）放在最上方。
- 分成「本場／策略與求路／技能與回復／關卡資料／說明與診斷」五張卡片；長說明預設收合。
- 按鈕加圖示；狀態文字依階段上色（進行中綠、受阻橙、故障紅）。
- 橫向時四個操作鈕排成一列。
- 新增「複製診斷」，內容與 PC 面板相同。
- 編輯頁顯示拖拉把手，下滑不會誤關而丟失草稿，請用「取消」或儲存離開。
- 轉一次、開始 Auto 與停止有觸覺回饋。

## 更新

替換新版 dylib 即可；活動 JSON 不需重新匯入（舊 JSON 照常使用，退回輸出只在已開啟 `preferBeforeOutput` 的 0.5.24 版 JSON 生效）。
