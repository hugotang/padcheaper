# PADCheaper 0.5.3-orbs

適用日服 PAD `jp.gungho.pad` 23.6.0／build 106878、arm64、最低 iOS 15。限定單人。

## 變更

- 修正四連旁有未消同色珠時被誤拒絕的問題。首批實際消除群組仍須恰好為直線 4 顆，五消與合併大組不符合。L／T／十字／3×3 保留既有判定。
- 光 T＋心四連等複合形狀加入補珠距離、干擾珠、布局衝突及最弱目標評分；保留不同缺項、布局與起點的候選。三種品質的原有時間及步數上限維持。
- 未達標訊息直接列出缺少的條件與組數，顯示實際求路耗時及時間上限，與拖珠秒數分開。
- 適配雲、普通／超暗闇、封條、固定起點、弱化／鎖／釘／Combo／刺珠、不可消及最少消除規則；支援邪魔、毒、猛毒與爆彈的盤面模型。
- 路線避開轉轉、封條及刺珠。轉轉枚舉所有共用色序相位，全部滿足目標與妨礙限制才可執行；不抓指定顏色。毒／猛毒的確定性消除、首批未消爆彈仍禁止執行。

詳細規則見 [盤面效果](orb-effects.md)、[四連搜尋](orb-shape-search.md) 及 [形狀目標](orb-goals.md)。不估算隨機天降、傷害、實際回復量或完整隊長技。

## 更新

完整關閉 PAD，在 LiveContainer 的 PAD Tweak Folder 替換 `PADCheaper.dylib`，避免同時載入重複舊版，使用有效憑證重新簽署 tweaks 後啟動。面板應顯示 `0.5.3-orbs`。保留 guest 容器內原有 config.json、隊伍庫與帳號檔；範例設定只供首次安裝參考。

先在單人關卡核對讀到的珠色、效果位置，再測「執行一次」及手動停止，最後才測連續技能。夜一新增的轉轉只有全相位都達標才放行，不保證每盤能續轉；舊版 0.5.2 的夜一停用說明仍適用於舊版。

## 驗證狀態

2026-10-29，已獲授權集中編譯測試。Windows 求解器／model 回歸通過；IMG_0407 的光 T＋心四連三檔在桌面均達成 3／3，路徑經獨立消除／四連 oracle 及重播核對。首次量測為快速 22 步、均衡 30 步、深入 44 步。

完整 iOS CI 與交付驗證進行中，完成結果見 [開發紀錄](development.md)。圖片轉錄不是原生快照，上述結果不代表真機耗時或技能結算；`device_verified` 維持 false，真機驗收見 [裝置清單](device-testing.md)。
