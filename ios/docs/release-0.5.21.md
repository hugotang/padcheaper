# 0.5.21-orbs：8 人開技確認與同場接續

修正 0.5.20 在 B2／B5 開完技能後，盤面已可操作卻因「技能使用次數未確認」停止的問題。原先將隊員的「限次技能使用量」誤當成普通開技次數；原生只有含 type 268 的限次技能才增加該欄位。新版核對實際技能 ID、固定版本角色、可見位置、本體來源及整場技能總數恰好增加一次，再等盤面穩定後繼續。

8 人使用場內活動固定版本的技能、效果與 CD，不能以普通圖鑑版本代替。兩格相同角色也必須各自核對位置。來源讀取沿用固定參數鏈及原生技能語意解析；新增測試刻意讓圖鑑技能與活動技能不同。

同一場停止後可再按 Auto 接續：保留已確認的回合、轉珠、開技、序列與停止原因，重新讀取現在的盤面。按停止時已啟動的技能仍由遊戲完成，程式只讀取完成紀錄；再次按 Auto 才繼續操作。若手動換盤／換層或改策略，舊序列餘下步驟會丟棄並重新規劃。原生啟動或完成紀錄不明時維持停止，不重試該技能；離開／重開遊戲不保留記憶體中的同場進度。

Dungeon Clear／結算即停止，下一場需重新按 Auto。使用範圍仍是一場 8 人本機技能與轉珠；3／4 人維持轉一次。詳見 [分析紀錄](../research/orb-eight-skill-resume-20261102.json) 及 [實機檢查](device-testing.md)。已匯入的本杯活動設定可繼續使用，這次不需重新匯入。
