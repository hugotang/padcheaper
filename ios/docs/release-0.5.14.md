# 0.5.14-orbs

本版修正 4 人結束後進入 3 人時，上一場的多人模式記錄可能使「轉一次」一直停用；並合併固定隊長解析、手動目標入口及 4 人其他玩家退出後的可用性修正。2026-10-31，[CI 87](https://github.com/hugotang/padcheaper/actions/runs/41202426621) 已通過完整自動回歸、iPhoneOS arm64 編譯與嚴格簽章、瀏覽器及四份 GUI。結果見 [開發紀錄](development.md) 及交付 `verification.json`；真機驗收仍待回報。

- 新入場識別通過重讀確認後，重新判定 3／4／8 人模式，即使中間沒有讀到大廳也能恢復。模式、selector、關卡樓層或記憶體位址單獨改變不會解除同場停用；空白、未完成或讀取中變動的識別不採用。上一場的持珠及一次性點擊權限一併撤銷。
- 4 人其他玩家退出時，核對退出席位與本機連線；只接受已檢查的原生恢復／退出狀態。本機斷線、重連初始化清掉持珠、結算或倒數結束時停止，恢復可用後仍須明確再點一次。
- 固定隊伍的隊長變體改用含特殊版本的資料總筆數，補入固定技能事實與精確首批珠數條件；4 人額外助人格沒有助人隊長技。隊長解析失敗仍可獨立設定手動目標，複製隊長條件時重讀目前資料。
- 診斷保留最多 16 筆 UI 觀察到的可用性變化，新增同步子步驟與退出席位／狀態。紀錄不能替代每幀或真機同步觀察。

更新前停止工作並完整關閉 PAD，依現有注入流程替換 dylib；LiveContainer 重新簽署。重開確認版本為 `0.5.14-orbs`，保留已存配置。舊版交付檔不覆寫。

優先驗收：不重開 app，打完 4 人後進 3 人，輪到自己時按一次；他人回合保持停用。接著測 3→4、4 人固定隊長、其他玩家退出後再點一次，以及真正本機斷線／結算仍停止。未點擊的下一盤不能自行開始。完整要點見 [真機測試](device-testing.md)。自動化與模擬器只能驗證本機流程，真機多人同步仍待回報，`device_verified=false`。
