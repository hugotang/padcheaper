# 0.5.39-orbs：連續多色取珠與路徑優化

日服 PAD 23.6.1／107553、arm64，最低 iOS 15。使用者已要求編譯測試，本版正在集中驗證；完整回歸、iPhoneOS 編譯／簽章、CI 及交付結果尚待完成。真機仍未驗證，`device_verified=false`。

- 單人一般目標與武裝無效回復共用最多六次連續取色，可在同一路徑補同色或多色。取色依完整隊伍／手動／當回合目標及實際色表，保留原有心四、T、Combo 與有效角色可發動的回復 L；色表沒有需要的顏色便不等待該色。
- 多轉轉盤可選其中一格連續取色，其餘格避開。目標格交換後的相位獨立於未觸碰格，終盤最多核對 36 組顏色；每次進出格由實際顏色、犧牲珠、珠子身分及盤面確認。逐珠動作狀態來自既有同次讀取，正常放手前等待非持珠穩定並重評全相位；取消、時間不足或狀態不符保留停止／放手處理。
- 珠量已足夠但位置難排時，從已選珠量方案再嘗試最多兩次額外交換，總數仍最多六次。原補珠候選保留，額外候選最多佔十二案中的四個空位、512 個新狀態計入總上限 8,192；只有額外方案通過最低操作時間預檢才保留約三分之一搜尋時間。這會重新分配搜尋成本，尚未證明整體速度或成功率改善。
- 普通基本珠路線可移除完整珠子身分排列與持珠位置相同的多餘循環，完整重播、附帶資料及全相位結果相同才發布，且只用原搜尋剩餘時間。fishing、活動模式及特殊珠狀態不套用此縮路。
- 診斷保留最近成功 fishing 及已確認武裝回復，包含逐次交換，避免被短歷史擠走；只限本次 Session，重開遊戲不還原。另記額外候選、各方案耗額／略過、實際嘗試與未搜尋入口，有限搜尋失敗不宣稱盤面無解。
